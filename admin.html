Bağlantı

GitHub deponuza yazabilmek için bir erişim anahtarı (token) gerekiyor. GitHub → Fine-grained token sayfasından yalnızca bu depoya, Repository permissions → Contents: Read and write yetkisiyle bir anahtar üretin (depo bergec hesabında olduğu için anahtarı o hesapla üretin). Anahtar yalnızca bu tarayıcıda, sizin belirlediğiniz admin şifresiyle şifrelenmiş olarak saklanır; hiçbir yere gönderilmez.

Görseller

Görselleri buraya bırakın ya da seçin; otomatik küçültülüp sayfanın içine gömülür (böylece onlar da parolanın arkasında kalır). Her görselin altındaki Metne ekle düğmesi, imlecin bulunduğu yere [[gorsel:1]] işaretini koyar — görsel yazıda o noktada çıkar.
